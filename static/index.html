    Nearby Wi-Fi networks

    Active scan via CoreWLAN: spot crowded channels, find a quieter band, or catch another access point broadcasting your network name. Takes a few seconds and briefly competes with your connection.

    Run a scan to see the networks around you.

    Remote access iOS companion

    Let the INS iOS app view this dashboard over your WiFi. Off by default. When on, INS listens on your LAN and every request needs the token below; access is read-only, so a phone can never change anything.

    Regenerating immediately disconnects any device using the old token.

    Notifications & webhooks

    Send alerts to Discord, Slack, Pushover, ntfy, or any HTTP endpoint. Paste the webhook URL; the receiver is detected and formatted automatically.

    Voice & Apple Shortcuts

    Speak serious alerts aloud, or run an Apple Shortcut on every alert or new device. The first Shortcuts run prompts macOS for Automation permission.

    Behavior

    Router quarantine experimental

    Connect INS to your router so Block on router in a device's detail view actually kicks it off the WiFi. Supports Unifi (REST) and OpenWrt (SSH). Use Test connection before relying on it.

    Join hook advanced

    Shell command run when a new device joins. Receives $DEVICE_IP, $DEVICE_MAC, $DEVICE_VENDOR, $DEVICE_HOSTNAME, $DEVICE_TYPE, $SSID as environment variables. Empty disables it.

    Passive sniffer

    Powers per-device bandwidth, DNS history, and auto-naming from DHCP. Needs one-time BPF access: run tools/enable_sniffer.sh with sudo, then restart INS.

    —

    Privacy

    Everything stays on your Mac. No cloud, no accounts, no telemetry. INS only reaches the internet to check GitHub for updates, plus any webhooks you configure above.
