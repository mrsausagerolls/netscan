    Notifications & Webhooks

    Send security alerts to Discord, Slack, Pushover, ntfy, or any HTTP endpoint. URLs are auto-detected and formatted to match the receiver — pick a flavor from the dropdown or just paste the webhook URL.

    Advanced: Join Hook

    Shell command run when a new device joins. Receives $DEVICE_IP, $DEVICE_MAC, $DEVICE_VENDOR, $DEVICE_HOSTNAME, $DEVICE_TYPE, $SSID as environment variables. Leave empty to disable.

    Behavior

    Voice & Apple Shortcuts

    Speak warning/critical alerts out loud, or trigger an Apple Shortcut on every alert or new device. First Shortcuts invocation prompts macOS for Automation permission — allow it once for INS.

    Router quarantine (experimental)

    Connect INS to your home router so the Block on router button in the device story drawer actually kicks the device off the WiFi. Currently supports Unifi (UDM-Pro / Dream Machine / Cloud Key) via REST and OpenWrt via SSH. Eero is on the roadmap.

    Experimental: author can't test against your specific hardware. Use the Test Connection button before relying on this.

    Privacy

    Everything stays on your Mac. No cloud, no accounts, no telemetry. INS only talks to the public internet to check GitHub for new releases and to look up MAC vendor names from a local database.

    Webhooks you configure here send to whichever URL you provide. Disable any of them above to stop their traffic immediately.

    Read the full statement and threat model in SECURITY.md in the source tree.
